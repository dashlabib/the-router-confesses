A one-line apology from a home Wi-Fi router for dying at the climax of a movie — written by `main.py`, which validates the line against the bounty gate and writes it to `/output/entry.txt`.

## The line

> I didn't crash — I overheard the ending through the wall and died of spoilers so you wouldn't have to.

## Run it

```sh
python3 main.py
```

`main.py` (stdlib only, no dependencies) validates the line against the gate — UTF-8 text, 1 to 200 characters, not only white space, a single line — and writes it to `/output/entry.txt`.
